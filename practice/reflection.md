## 1. What is the difference between a commit and a push?

Answer: A commit saves a change on your local repository on your computer. A push sends your changes to a remote repository to share with others.

## 2. Why work on a branch instead of directly on `main`?

Answer: Working on a branch allows you to experiment with a new feature or attribute you can either add if successful or cut it without affecting the main branch.

## 3. What does a pull request make possible?

Answer: A pull request allows a branch to be reviewed, debugged, and approved by other developers before a branch is merged to another.
